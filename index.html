Platform Features

Everything You Need for a Fair Election

Built for school administrators and student voters. Simple to set up, powerful in action.

Token-Based Access
Each voter receives a unique SW-XXXX-XXXX-XXXX token. One token, one vote — no duplicates, no fraud.
Identity-Protected Voting
Your name is never shown in results. Votes are recorded securely — only your token is used to verify participation, never your identity.
Live Results
Real-time vote counts powered by Supabase Realtime. Watch the results update live as votes are cast.
Winner Declaration
Automatic winner cards per position. Publish results publicly after the election closes.
Full Audit Trail
Every admin action is logged — election changes, token generation, and status updates. Full transparency.
Bulk CSV Upload
Upload your entire voter list as a CSV file and generate tokens for all students in seconds.
Voting Control
Start, pause, and end elections with a single click. Emergency pause protects vote integrity.
Candidate Profiles
Add candidate photos, bios, and manifestos. Voters see rich profiles before making their choice.
Mobile Friendly
Students vote from any device — phone, tablet, or desktop. Fully responsive design throughout.
