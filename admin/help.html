Elections
5 articles
How do I create a new election?
▼
Go to Elections Manage Elections and click + New Election. Fill in the election name, description, and optional date range, then click Save. Your election starts in Draft status — it won't be visible to voters until you activate it.
Tip: You can create and configure elections in advance. Only activate when you're ready for voting to begin.
How do I add positions and candidates?
▼
  1. Go to Candidates Manage Candidates
  2. Select your election from the dropdown
  3. Add positions (e.g. President, Vice-President)
  4. For each position, add candidates with their name, photo, and bio
Candidates without photos will show a default avatar on the ballot.
▶
How do I start, pause, or end an election?
▼
Go to Voting Voting Control. You'll see buttons to:
  • ▶ Start — opens voting to all token holders
  • ⏸ Pause — temporarily suspends voting (tokens stop working)
  • End Election — permanently closes voting
Ending an election is permanent and cannot be undone.
Can I run multiple elections at the same time?
▼
Yes. STACKWEB supports multiple elections in different states simultaneously. Each election has its own set of voters, tokens, positions, and candidates — completely isolated from each other.
Can I edit an election after it's active?
▼
Basic details (name, description) can be edited. However, adding or removing candidates during an active election is not recommended as it may affect vote counts. Always pause the election before making structural changes.
Never delete positions or candidates while an election is active.
Tokens & Voters
5 articles
How do voting tokens work?
▼
Each voter receives a unique token in the format SW-XXXX-XXXX-XXXX. Tokens are:
  • One-time use — marked "used" immediately after voting
  • Anonymous — not linked to voter identity in the vote record
  • Election-specific — only valid for the election they were generated for
How do I generate tokens for all my voters?
▼
Go to Token Generator. You have two options:
  1. Manual — enter the number of tokens and click Generate
  2. CSV Upload — upload a CSV file with columns: name, email, class
After generating, download the tokens as a CSV to distribute to voters.
CSV format: First row should be the header name,email,class
What if a voter loses their token?
▼
Go to Voters Voter Management, find the voter, and look up their token in the table. You can re-send it to the voter. If the token was compromised, revoke it and generate a new one for them.
How do I revoke a token?
▼
In Voter Management, find the voter row and click Revoke. The token immediately becomes invalid — the voter will see an error if they try to use it. You can then generate a new token for them.
Can a voter vote more than once?
▼
No. Each token can only be used once. The moment a voter submits their ballot, the token status changes to "used" and any further attempts with the same token will be rejected. This is enforced at the database level.
Security
4 articles
Are votes truly anonymous?
▼
Yes. When a vote is cast, the system records which candidate received a vote but does not link that vote to the voter's identity or token. Even the admin cannot see who voted for whom — only total vote counts per candidate.
What happens after too many failed login attempts?
▼
After 5 failed login attempts, the admin login is locked for 15 minutes. This prevents brute-force attacks. The lockout is stored locally in the browser. To unlock early, clear your browser's local storage for this site.
How is the data secured?
▼
STACKWEB uses Supabase with Row Level Security (RLS) on every table. This means:
  • Only authenticated admins can read/write election data
  • Voters can only read data relevant to their election
  • No data can be accessed without proper authentication
  • All data is transmitted over HTTPS
What does the Audit Log track?
▼
The Audit Log records every admin action including:
  • Admin logins and logouts
  • Election creation, modification, and status changes
  • Token generation and revocation
  • Candidate additions and deletions
  • Settings changes
View it under System Audit Logs.
Results & Reports
4 articles
When can voters see the results?
▼
Results are only public when you enable Public Results in the election settings. You can toggle this at any time — even before closing the election if you want live public results, or only after closing for a final reveal.
How are winners determined?
▼
Winners are determined by simple majority — the candidate with the most votes per position wins. In case of a tie, all tied candidates are shown as winners. The system does not automatically break ties.
Can I export the results?
▼
Yes. In Analytics, click Export Report to download a CSV file containing all vote counts per candidate per position. You can also export the voter list with their token status from Voter Management.
>
Are results updated in real-time?
▼
Yes. The Analytics and Voting Control pages use Supabase Realtime to update vote counts instantly without needing to refresh the page. The voter turnout bar and candidate standings update live as votes come in.
